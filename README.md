# Nepal Land Document Assistant

A structured research and design project exploring how technology can assist with land document processing in Nepal. The goal is to understand the domain, define requirements, and produce system designs before any implementation begins.

## Project Phase

**Phase 0 — Documentation & Research.** The repository is in its initial setup phase. No technology choices have been made. No application code has been written. Current work focuses on domain research, requirement gathering, and system design within an Obsidian-based documentation vault.

## Repository Purpose

This repository serves as the single source of truth for project documentation, domain knowledge, architectural decisions, and designs. All work is captured as structured Markdown documents. The project will proceed to implementation only after sufficient research and design work is complete.

## Obsidian Documentation Vault

The `docs/obsidian-vault/` directory is an Obsidian-compatible knowledge base organized by topical areas. It contains:

- Domain research notes
- Document analysis and OCR research
- Software requirements (functional, non-functional, business rules)
- System design documents
- UML diagrams (described in Mermaid)
- Data design
- Architecture Decision Records (ADRs)
- UI/UX documentation
- Testing strategy
- Open questions, glossary, and decision log

## High-Level Roadmap

1. **Phase 0** — Documentation & Research (current)
   - Set up repository and vault structure
   - Research land document domain
   - Explore OCR and document-generation technologies
   - Define requirements and system design
   - Capture architecture decisions

2. **Phase 1** — Design & Prototyping
   - Refine UML models
   - Create UI/UX wireframes
   - Validate design with stakeholders

3. **Phase 2** — Implementation
   - Select technology stack
   - Build backend and frontend
   - Integrate OCR and document generation

4. **Phase 3** — Testing & Deployment
   - Write and execute test suites
   - Deploy to staging and production
   - Document operational procedures
